## 起源:从种子 5、6 到暂存区

### 种子 5:文件关系发现(评估后降级)

**第一层(同名不同后缀关联)**:搜"报告"出来 DOCX,提示同目录有 PDF/PPTX。
- 评估:对"分门别类储存、记得文件在哪"的用户价值薄——用户会直接搜"报告.pdf"或 ext:pdf,不需要系统提醒。够不上"种子",属于可选小便利。

**第二层(连续打开关联)**:history 时序统计"开 A 后常开 B"。
- 评估:关联质量无可靠保证(噪声率高),不上 AI 靠时序统计和阈值降不下去,上 AI 违背"薄"。死结,不值得做。

### 种子 6:临时工作集(评估后保留,长出暂存区)

**第二层(动态集合)、第三层(工作集跟随你走)**:自动发现任务边界、自动判断工作集有效性。
- 评估:和种子 5 第二层同一个命门——自动推荐质量撑不住,不上 AI 不可靠,上 AI 违背"薄"。这三个自动发现层全部砍掉。

**第一层(静态工作集)**:手动圈定跨目录文件组,命名召回。
- 评估:唯一有价值的层。判据是"用户是否有跨目录同时处理一组文件的场景",用户确认有。

### 突破:暂存区联动拖拽

用户提出:开发一个暂存区,搜到文件扔进去,需要时拖出去。这绕开了自动推荐的质量死结——不靠系统猜关联,靠用户自己往里扔。系统不推荐,系统只暂存。

## 核心模型:暂存区是工作台,工作集是档案柜

### 统一关系

工作集是暂存区的子集。暂存区是那个唯一的容器,工作集是容器里被打过标记的文件。不是两个并列的东西,是一个东西里的两个层次。

| | 暂存区 | 工作集 |
|---|---|---|
| 数量 | 唯一,一个 | 多个 |
| 状态 | 当前活跃,随时在加在删 | 稳定存档 |
| 存储 | 内存轻持久(关 Prism 再开还在) | 落盘(挂 history 旁标注表) |
| 显示 | 常驻在 Prism 窗口(空则收起) | 不常驻,召唤才出现 |
| 诞生 | 用户往里扔文件就有 | 暂存区转正,或手动建 |

### 零摩擦加入(替代主动推荐)

暂存区始终可用,不依赖工作集。有活跃工作集时,往暂存区加的文件自动带工作集标记。用户的动作本身就是最准的信号——按 `+` 就是觉得该加,系统不用猜。

### 持久化规则

- 属于工作集的文件:自动落盘到工作集(零摩擦加入的延伸)
- 不属于任何工作集的文件:暂存区自身轻持久化(关 Prism 再开还在,像浏览器未保存标签页)
- 满了最早未标记的被挤掉(LRU),工作集文件挤不掉(已归档)

### 载入工作集时的保留规则

载入"9月报告"时:
1. 暂存区里属于"8月报告"的文件 → 移除引用(工作集档案不动,下次载入还在)
2. 暂存区未标记文件 → 保留(用户当前正在处理的,不能丢)
3. "9月报告"工作集文件 → 加入暂存区,标记为"9月报告"

结果:暂存区 = 未标记文件 + 新工作集文件。旧工作集从暂存区消失但没丢。

### 数量上限

- 默认 5 个,可在设置中自定义调高
- 满了最早未标记的被挤掉(LRU),工作集文件挤不掉
- 自定义开关:默认小守安静,需要时放开

## 外观设计

### 位置

搜索框下方,结果列表上方,横向带状。空时收成几像素细线不占地方,有文件展开。

### 空暂存区

```
┌─────────────────────────────────────────────┐
│  🔍 weixin                              [⚙] │
├─────────────────────────────────────────────┤
│                                             │  ← 几像素细线,不占地方
├─────────────────────────────────────────────┤
│  (结果列表)                                 │
└─────────────────────────────────────────────┘
```

### 有文件的暂存区(一行高度,紧凑)

```
┌─────────────────────────────────────────────┐
│  🔍 8月                              [📁][⚙] │
├─────────────────────────────────────────────┤
│ ⊕3 📄报告 📊8月 📷素材          [清][存]     │  ← 一行高度
├─────────────────────────────────────────────┤
│  📄 8月报告.docx        D:\工作\             │
│  📊 8月数据.xlsx        D:\数据\             │
│  (结果列表)                                 │
└─────────────────────────────────────────────┘
```

- 一行高度,等于一行搜索结果的高度
- `⊕3` 左边小数字,当前文件数
- 文件名横排,不显示完整路径(悬停 tooltip 显示),截断到能认出的长度
- 属于工作集的文件名带视觉标记(小点 `●` 或淡色背景),没标记的不带
- `[清][存]` 单字按钮(清空、存为工作集)
- `[📁]` 工作集入口,`[⚙]` 设置
- 背景半透明,视觉权重低于搜索框和结果列表,余光可见不抢视线

### 点开工作集入口

```
┌─────────────────────────────────────────────┐
│  🔍                                [📁][⚙]   │
├──────────────────────┬──────────────────────┤
│ ⊕3 📄报告 📊8月 📷素材│ 工作集                │
├──────────────────────┤ ─────────────────    │
│  📄 8月报告.docx      │ 8月报告  3个 [载]    │
│  📊 8月数据.xlsx      │ 9月报告  5个 [载]    │
│  (结果列表)           │ 项目参考 2个 [载]    │
└──────────────────────┴──────────────────────┘
```

右侧弹出工作集列表:名字 + 文件数 + 载入按钮。

## 操作流

### 加文件
搜到文件 → 选中按 `+` 或拖动 → 进暂存区(零摩擦,有活跃工作集自动标记)

### 用文件
从暂存区拖出去到任意应用(邮件/聊天/编辑器),或点击暂存区文件名打开

### 存为工作集
暂存区攒够 → 点`[存]` → 起名 → 落盘归档

### 召回工作集
搜索框打名字(如"8月报告")→ 结果列表显示整组,或从`[📁]`入口载入到暂存区

### 清空
点`[清]`清空暂存区未标记文件(工作集文件不清,已归档)

## 和其他设想的关系

- **拖拽**:暂存区让拖拽两方向都有意义(拖入暂存、拖出使用),且暂存区不随 Prism 主窗口失焦隐藏,拖拽不会被中断
- **别名**:别名是 `路径 → [词]`,工作集是 `名字 → [路径列表]`,共用 history 旁标注层
- **快捷键**:`+` 加入暂存区是窗口级快捷键,和其他高频动作快捷键同一套
- **多选**:暂存区吸收了多选拖拽的复杂度——一个一个扔进去,凑齐一起拖出去,不用 Ctrl 多选
