## 批次0：小问题（docs/小问题.md）

- **Q1 设置页网页搜索 UI**：`SettingsWindow.xaml` web 选项卡 Row 2 同时叠放按钮行、分隔线、在线联想区三个子元素。改为独立行；添加/删除/恢复预设改为三个大按钮（带说明文字的方框，非小文字按钮）。
- **Q2 文件夹搜索中网页模式仍显示当前目录前缀**：`AppState` 增加 `IsWebMode`；`RunSearchAsync` 网页模式置位；`SearchWindow` 在网页模式下隐藏范围标签（仅表现层，Ctrl+G 与底层范围不动）。
- **Q3 网页搜索时网址类文本应直接打开**：`WebModeDetector.TryGetDirectUrl`（纯函数，scheme 或域名形态判定，含 localhost/端口/路径，拒绝版本号与 Windows 路径）；命中时直接结果改为"打开 URL"，跳过联想。

验证：`dotnet test`（新增 WebModeDetector URL 判定、IsWebMode 切换测试）。
