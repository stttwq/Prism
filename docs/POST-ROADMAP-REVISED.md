## 1. 产品定位

Prism 的核心定位是：**面向个人使用的轻量、快速文件与应用搜索启动器**。

窗口切换、内置文件动作和网页关键词搜索是受控扩展，但不得改变以下基础约束：

- 本地搜索必须保持低延迟、低常驻内存和可解释排序；
- LocalSystem indexer 只负责索引与受限搜索，不执行用户会话 Shell 动作；
- UI 始终由 Prism 独立弹窗承载，不注入或嵌入其他进程；
- 任何联网能力必须显式、可关闭，并与本地搜索延迟隔离。

目标环境固定为 **Windows 11 x64**。当前个人兼容性基线是 Windows build 22631 与 Directory Opus 13.23。

## 3. 搜索、排序与拼音

### 3.1 统一排序

文件、文件夹、应用和窗口使用同一套可解释排序框架：

1. 字面匹配高于所有拼音匹配；
2. 拼音内部全拼高于首字母；
3. 同类匹配比较精确、前缀、中间位置；
4. 使用历史只在同一匹配等级内加权；
5. 类型只作为最终稳定平局规则，不再固定“所有应用都排在文件前面”。

搜索必须按请求的 `max` 维护全局 Top-K，跨卷统一比较。首屏保持 8 条，用户展开后保持 1000 条；不得引入固定 200 条候选上限。

### 3.2 拼音行为

拼音默认开启，用户可关闭。覆盖：

- 文件名；
- 文件夹名；
- 应用显示名；
- 打开窗口的标题与应用名。

不对父路径做拼音匹配。

必须支持：

- `wx`、`weixin` → `微信`；
- `weix`、`xin` → `微信`；
- 从任意汉字位置开始匹配；
- `wx2026`、`weixinbeta` 等汉字/拉丁字母/数字连续输入；
- 大小写不敏感；
- `v` 与 `ü` 等价；
- 忽略拼音中的空格和撇号；
- 简体中文和常用繁体中文；
- 常见词组词典优先解决多音字，其余使用默认读音。

明确不支持：

- `eix` 这类非音节边界起始；
- `wxkaifa` 这类首字母与全拼混合缩写；
- 错别字、近音或读音模糊纠错。

只有查询包含至少两个拉丁字母时才启用拼音路径。拼音命中必须高亮对应汉字，而不是高亮不存在的拉丁字符。

拼音数据采用版本化、可独立卸载的 sidecar。关闭拼音后必须释放可选数据；损坏、版本不匹配或重建期间必须退回字面搜索。**额外常驻内存 ≤10MB 是验收目标，不是当前实测事实。**

### 3.3 使用历史

历史默认开启，可在设置中关闭，并始终提供一键清除：

- 最多 500 条；
- 超过 90 天未使用自动淘汰；
- 记录文件、文件夹、应用和窗口的成功使用；
- 网页查询和联想词不写入历史；
- 关闭时询问是否同时清除已有数据；
- 历史文件位于普通用户数据目录，带 schema 版本并使用安全替换写入；
- 损坏时回到空历史，不影响搜索主流程。

## 4. 当前目录与宿主联动

### 4.1 支持矩阵

首版只承诺：

- Windows Explorer；
- Windows 系统应用使用的标准打开/保存对话框；
- Directory Opus 13.23。

不承诺浏览器、Office、其他第三方文件管理器、32 位宿主、提权宿主或旧式非标准对话框。

### 4.2 搜索范围

- 从支持的宿主呼出 Prism 时，默认限定宿主当前目录；
- 搜索当前目录及全部子目录；
- 搜索框显示明确的“当前目录”范围标签；
- 点击标签或按 `Ctrl+G` 在当前目录与全局范围间切换；
- 总开关默认开启，用户可在设置中关闭；
- 目录识别失败时立即退回全局搜索并提示，禁止沿用上一次路径。

索引实现不得给 12B `NodeSlot` 伪造“复用 flags 即可零内存保存子指针”的方案。低内存首版应先按名称生成候选，再通过现有 `parent_record` 链验证候选是否位于 root 下；只有基准证明不足时才评估额外子树结构。

### 4.3 结果交回

- 标准打开/保存对话框：Prism 只导航文件夹或填入/选中文件，最终“打开/保存”由用户确认；
- Explorer/Opus：Enter 保持普通打开语义，`Ctrl+Enter` 才让原宿主定位或导航到结果；
- UIA/COM/Opus 接口失败时保留 Prism 结果并给出可恢复提示；
- 不以 DLL 注入作为降级方案。

### 4.4 空输入

- 在 Explorer、标准系统对话框或 Opus 上下文中，空输入显示当前目录相关的最近文件/文件夹；
- 其他上下文中，空输入显示最近窗口；
- 输入 `>` 后无条件切换到窗口模式。

## 5. 窗口切换器

窗口功能严格限定为“搜索并切换”：

- `>` 前缀进入全量窗口搜索；
- 匹配窗口标题和应用名；
- 支持与文件搜索一致的字面、拼音和历史规则；
- 只枚举当前可切换的可见顶层窗口；
- 最近窗口历史可跨重启保存，但展示时只保留当前仍存在的窗口；
- 切换失败时显示错误，不尝试注入或结束目标进程。

明确不做：关闭、最小化、最大化、还原、置顶、分屏、跨显示器移动或结束进程。

## 6. 内置动作

### 6.1 文件与文件夹动作

保留现有：

- 打开所在位置；
- 复制；
- 剪切；
- 复制路径。

新增：

- 复制到；
- 移动到；
- 重命名；
- 用其他应用打开（仅文件）；
- 移入回收站；
- 永久删除；
- 属性；
- 压缩为 ZIP。

### 6.2 应用动作

应用结果增加：

- 打开真实可执行程序所在位置；
- 复制真实可执行程序路径；
- 属性；
- 以管理员身份运行。

动作针对解析后的目标程序；普通启动仍保留 `.lnk` 的参数和工作目录。无法可靠解析目标时隐藏不适用动作。

### 6.3 交互与安全

- 单次只处理一个结果，不引入多选；
- “复制到/移动到”先显示最多 8 个最近目录，再提供“搜索更多”；
- 最近目录优先取历史复制/移动目标，再补充近期访问目录；
- 文件冲突、权限、进度和取消交给 Windows `IFileOperation`；
- 永久删除始终显示系统确认，且不能关闭确认；
- 重命名在 Prism 内联完成，默认只选中文件名主体；
- 压缩始终生成 ZIP：优先调用本机 7-Zip，未安装时使用 Windows 11 可用能力；
- 不枚举任意 Shell 压缩扩展，不调用 WinRAR；
- 打开、定位、属性、打开方式、复制、剪切、复制路径成功后隐藏 Prism；
- 重命名、移动、删除、压缩后保留窗口，等待 generation 更新并刷新结果。

Shell、剪贴板、COM、用户设置和外部程序启动必须留在普通权限 broker/WPF 用户会话中，禁止下沉到 LocalSystem indexer。

## 7. 高级搜索语法

只实现 `ext:` 和 `path:`：

```text
report ext:pdf
design ext:md,pdf path:"Project Docs"
```

规则：

- 普通词始终是名称查询；
- `ext:` 多值以逗号表示 OR；
- 多个不同过滤器之间取 AND；
- `path:` 对规范化完整路径做字面、不区分大小写的子串匹配；
- 带空格值使用引号；
- 未识别 token 按普通文本处理；
- 过滤必须发生在 Top-K 选择前，不能先截断再过滤；
- 使用 `ext:` 或 `path:` 时只返回文件/文件夹，不混入应用、窗口或网页结果。

不实现 `size:`、`datemodified:`、自然语言日期或负向过滤。

## 8. 网页搜索增强

### 8.1 专用网页模式

识别内置或自定义网页关键词后进入专用网页模式，不再混入本地文件和应用：

1. 首行始终立即显示“搜索原词”；
2. 在线联想开启时，后续最多显示 5 条建议；
3. 选中原词或联想后使用系统默认浏览器打开；
4. 网页查询不进入 Prism 历史。

### 8.2 在线联想

- 默认关闭，用户必须主动开启；
- 只支持内置 Bing、百度和 Google；
- 自定义引擎不提供联想 API 配置或自动发现；
- 只在识别出网页关键词后发送剩余查询；
- 查询变化立即取消旧请求；
- 原搜索行不等待网络；
- 联想请求 800ms 未返回即放弃，本次不显示错误；
- 响应无效、断网或限流不得影响本地搜索和直接网页搜索。

### 8.3 图标

- 内置引擎使用随程序打包的图标；
- 自定义引擎保存或 URL 变化时，单独提示是否联网获取 favicon；
- favicon 本地缓存并设置响应大小、类型和解码上限；
- 获取失败或用户拒绝时使用通用网页图标；
- favicon 授权与在线联想开关相互独立。

## 9. 性能与验收门

### 9.1 硬门槛

- 三进程 Release 总内存：**≤100MB**；
- 拼音 sidecar 额外常驻内存目标：**≤10MB**；
- 暖查询 `max=8`：端到端 P95 **≤100ms**；
- 暖查询 `max=1000`：端到端 P95 **≤300ms**；
- 在线联想不计入本地搜索延迟，但受 800ms 单次超时约束。

旧两进程 38MB、总内存 43–45MB、拼音固定增加 1MB 等数字均不是当前事实。40–45MB 只可作为重新测量后的优化期望。

### 9.2 正确性门

- 全局排序覆盖全部卷；
- 候选阶段不构造完整路径，只为最终 Top-K 生成路径；
- 8/1000 上限与“展示更多”行为保持兼容；
- 截断结果不能被前端当作完整集合继续过滤；
- root、`ext:`、`path:` 必须在 Top-K 前生效；
- 拼音关闭、sidecar 损坏或联想断网时均保留字面本地搜索。

### 9.3 质量门

- Rust tests；
- Clippy `-D warnings`；
- 新增 C# 单元测试；
- WPF Release build；
- Windows 11 x64 机器验收；
- Explorer、系统打开/保存对话框、Directory Opus 13.23 兼容性验收；
- 三进程内存与搜索延迟复测。
