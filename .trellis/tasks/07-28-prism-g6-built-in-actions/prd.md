# G6 完整内置动作

## Goal

为单个文件、文件夹和应用结果提供完整但封闭的内置动作集合，所有 Shell/COM 文件操作在普通权限 broker 的专用 STA worker 上执行，并由 Windows 处理冲突、权限、进度和取消。

## Requirements

- 强依赖 G2 历史和 G3 typed target、Shell/COM worker、日志及权限边界。
- 文件/文件夹动作：定位、复制、剪切、复制路径、重命名、属性、复制到、移动到、移入回收站、永久删除、压缩；“打开方式”仅用于文件。
- 应用动作：定位真实可执行程序、复制目标路径、属性、以管理员身份运行；`.lnk` 启动继续保留既有参数，但目标类动作针对解析后的真实程序。
- 一次只处理一个搜索结果，不增加多选、JSON 命令、DLL 插件、任意 Shell verb 或脚本动作。
- 复制到/移动到进入显式子流程：先显示最多 8 个最近目标，历史操作目标优先、近期访问目录补足，底部可搜索全部文件夹；取消返回原动作列表并恢复查询/选择。
- 复制、移动、回收站、永久删除使用 `IFileOperation`；Windows 标准 UI 处理重名、权限、进度和取消。
- 永久删除每次显示系统确认，不能关闭确认；回收站与永久删除的文案、图标和动作 id 明确区分。
- 重命名在 Prism 内联编辑，默认选中文件名主体、不选扩展名，提交后由 Shell worker 执行；非法名/冲突保留编辑态并显示错误。
- 压缩始终生成 ZIP，优先调用本机已安装的压缩程序（自动探测 7-Zip）；用户可在设置中自定义压缩程序的目录路径，设置值优先于自动探测；两者都不可用时回退到 Windows 内置 Shell 压缩能力。不调用任意第三方 Shell 扩展。
- 打开、定位、属性、打开方式、复制、剪切、复制路径成功后隐藏 Prism；重命名、移动、删除、压缩后保留窗口，等待 generation 更新或有界超时后重搜。
- generation 超时只提示索引尚未刷新，不能把已成功的文件操作标为失败。
- 仅成功动作更新 G2 历史；用户取消不是失败，不写错误日志或成功历史。

## Acceptance Criteria

- [ ] 每个 result kind 只显示规范允许的动作，Unknown/失效 target 不执行副作用。
- [ ] 复制到/移动到的 8 个最近目标、来源优先级、全目录搜索、取消恢复和单选约束有状态测试。
- [ ] 重名、权限拒绝、取消、长路径、中文路径、只读、源消失、复制到自身、移动到子目录有机器测试。
- [ ] 回收站与永久删除严格区分，永久删除每次显示不可关闭的系统确认。
- [ ] 重命名默认选中主体、不选扩展名，非法输入不离开编辑态。
- [ ] 本机压缩程序存在、自定义路径设置、两者都缺失回退 Windows 内置三条路径都生成 ZIP，目标冲突不静默覆盖。
- [ ] `.lnk` 启动参数不回归，应用定位/路径/属性针对真实目标，管理员运行使用 Windows 正式提升。
- [ ] 所有 Shell/COM 调用发生在普通权限 broker STA worker，LocalSystem indexer 无动作命令。
- [ ] mutation 后 generation 刷新或超时提示符合规范，成功/取消/失败历史与日志正确。
- [ ] Rust tests、Clippy、C# tests 和 WPF Release build 全部通过。

## Out Of Scope

- 多选和批处理；
- JSON/DLL 插件、任意命令、任意 Shell verb；
- 非 ZIP 压缩格式（7z、rar、tar.gz 等）；
- 关闭永久删除确认；
- 在 LocalSystem indexer 执行动作。

## Dependencies

强依赖 G2、G3。
