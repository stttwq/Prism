# Prism 技术设计（第一版）

> 面向非技术读者的说明在括号里，正文保留必要的技术词供开发时使用。

## 技术选型（按用户要求：Rust 后端 + C# 前端）

- **后端（干重活的部分）：Rust**。独立进程 `prism-core.exe`，负责文件索引、搜索、程序清单、网页关键词解析。Rust 内存占用小、速度快，是满足"100MB 内存上限"的关键。
- **前端（看得见的部分）：C# + .NET 8 + WPF**。进程 `Prism.exe`，负责搜索窗口、设置页、托盘图标、全局快捷键。
- **两者通信**：本机命名管道（Named Pipe）+ JSON 消息（前端把输入文字发给后端，后端把结果列表发回来）。前端启动时拉起后端进程并守护（后端崩溃自动重启）。

## 架构与模块

### Rust 后端（prism-core）
1. **索引模块**
   - 首次启动对所有本地 NTFS 盘全量扫描建文件名索引；缓存到 %LocalAppData%\Prism。
   - 优先读 NTFS MFT/USN Journal（秒级建索引 + 实时增量更新，需管理员权限）；无权限降级为目录遍历 + 定时刷新。
   - 内存预算：索引用紧凑结构（路径前缀压缩 + 紧凑字符串池），目标全盘 200 万文件 ≤ 60MB；整个后端进程 ≤ 70MB。
2. **搜索模块**：子串匹配（不区分大小写），排序＝程序 > 最近使用 > 路径短；防抖 50ms，返回上限 100 条。
3. **程序清单**：扫描开始菜单 .lnk 与已安装应用，含中文显示名。
4. **网页关键词**：解析 `g 天气` 类输入，返回"打开网址"指令，由前端调默认浏览器。

### C# 前端（Prism.exe）
5. **界面**：以任务目录 frontend-spec.md（v2 复刻版）为唯一视觉与交互规格——1:1 复刻 `界面/` 下三张 Listary 截图：实色白卡片（不用亚克力）、圆角 10、蓝色匹配高亮、Ctrl+1..9 直达、"展示更多"行、→ 键动作面板、右上角固定窗口按钮；深/浅色跟随系统。内存预算 ≤ 30MB。
6. **全局快捷键**：低级键盘钩子实现"双击 Ctrl"，组合键用 RegisterHotKey；设置页可改。
7. **常驻与设置**：托盘图标（设置/退出）；注册表 Run 键自启；设置存 JSON（快捷键、网站关键词、自启开关），前后端共享。

## 数据流

键盘钩子 → 显示窗口 → 输入文字经命名管道发给 Rust 后端 → 后端合并（程序、文件、网页关键词）排序返回 → 前端渲染列表 → 回车把所选项发回后端确定动作 → 前端执行（打开文件/所在文件夹/启动程序/开浏览器）。

## 重要权衡

- 双进程比单进程复杂一点，但换来内存小、速度快、后端崩溃不拖垮界面，符合用户三条硬要求。
- MFT 读取需管理员权限：默认请求；拒绝时降级目录遍历（首次慢，功能不缺）。
- 不做文件内容搜索、不做对话框注入，第一版风险可控。

## 内存护栏（100MB 硬指标）

- 后端 ≤ 70MB + 前端 ≤ 30MB；执行计划中每步完成后用任务管理器实测，超标即优化（缩小结果缓存、索引结构调优），不留到最后。

## 安装与数据目录

- 安装器：Inno Setup 制作中文安装向导（选目录、开始菜单快捷方式、可选开机自启勾选）；安装路径全程支持中文/Unicode。
- 数据目录策略：启动时探测"安装目录\data"是否可写——可写则索引与设置都放这里；不可写（如 Program Files）自动使用 %LocalAppData%\Prism，并在设置页显示实际位置。所有路径处理统一走 Unicode API，中文路径全链路（索引、搜索、打开文件、管道消息）无损。

## 回滚/运维

- 索引缓存损坏自动重建；设置损坏恢复默认并提示。
- 后端进程崩溃由前端自动重启并重连。
