# Prism：Listary 替代品（第一版 MVP）

## Goal

从零开发一个 Windows 后台常驻的快速搜索/启动工具 Prism，替代 Listary 的日常核心用法：双击 Ctrl 呼出搜索框，即时搜到全盘文件并打开、启动软件、快捷搜网页。用户为非软件专业背景，所有沟通与界面文字使用中文。

## Requirements

### R1 文件搜索
- 全盘（所有本地硬盘）按文件名搜索，不搜文件内容。
- 输入时即时出结果（边打字边刷新）。
- 结果操作：回车打开文件；另一快捷键打开文件所在文件夹。

### R2 快速启动软件
- 在同一搜索框输入软件名（含中文名，如"微信"）可直接启动已安装的程序。
- 程序结果排在普通文件之前。

### R3 网页快捷搜索
- 预设常用引擎：如 `g 关键词`=Google、`b 关键词`=百度、`bi 关键词`=Bing，用默认浏览器打开。
- 设置里可自定义添加任意网站的搜索关键词。

### R4 呼出与外观
- 默认双击 Ctrl 呼出屏幕中央搜索框，按 Esc 或点击别处隐藏；设置里可改为其他快捷键。
- 界面简洁现代，跟随 Windows 系统深浅色自动切换；界面文字仅中文。

### R5 运行方式
- 开机自启、后台常驻，任务栏托盘图标（含退出、打开设置入口）。

### R6 性能与观感（用户强调）
- 常驻时整体内存占用不超过 100MB（含索引）。
- 界面要足够好看：精致的现代视觉（圆角、阴影、流畅动画、清晰排版），观感不输 Listary/PowerToys Run。

### R7 安装与数据存放
- 提供带安装向导的安装包（可选安装目录，支持中文目录）。
- 索引与设置默认存放在安装目录下的 `data` 文件夹；若该位置系统不允许写入（如 Program Files），自动改存用户数据文件夹，并在设置中显示实际位置。

## Acceptance Criteria

- [ ] 双击 Ctrl 在任何程序前台时都能呼出搜索框；Esc 隐藏；快捷键可在设置中修改并生效。
- [ ] 输入文件名片段，1 秒内显示全盘匹配结果；回车打开文件；指定快捷键打开所在文件夹。
- [ ] 输入"微信"等已安装软件名可搜到并启动该软件，且排在文件结果前。
- [ ] 输入 `g 天气` 用默认浏览器打开 Google 搜索"天气"；设置中新增自定义网站关键词后同样可用。
- [ ] 设置开机自启后重启电脑，Prism 自动在后台运行，托盘有图标，可退出。
- [ ] 系统切换深/浅色后，搜索框外观随之切换；界面全部为中文。
- [ ] 索引建好后在任务管理器观察，Prism 全部进程内存合计 ≤ 100MB。
- [ ] 界面有圆角、阴影、深浅色主题与打开/隐藏动画，视觉完成度经用户确认满意。
- [ ] 通过安装向导把 Prism 装到一个含中文的目录（如 D:\工具\Prism），全部功能正常；索引出现在安装目录的 data 文件夹内。
- [ ] 装到 Program Files 时软件仍正常，索引自动存到用户数据文件夹且设置页显示实际位置。

## Out of Scope（以后版本再做）

- "打开/保存文件"窗口增强（Listary 的对话框跳转功能）。
- 搜索文件内容（Word/PDF 里的文字）。
- 中英双语界面。
