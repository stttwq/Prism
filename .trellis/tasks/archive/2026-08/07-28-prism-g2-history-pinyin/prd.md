# G2 使用历史与拼音

## Goal

在不改变字面匹配最高优先级的前提下，为文件、文件夹、应用和窗口建立受控历史排序，并实现可关闭、可卸载、损坏可降级的全拼与首字母搜索。

## Requirements

- 强依赖 G1 的稳定 kind、匹配等级、Top-K、generation 和 C# 测试地基，以及 **G3 定型的 schema 版本约定**。
- 历史由普通权限 broker 保存，默认开启，可关闭、一键清除；最多 500 条，90 天未使用自动淘汰。
- 仅成功的打开、定位、动作或窗口切换更新相应计数和 `last_used_utc`；网页查询与联想不写历史。
- 历史文件**沿用 G3 定型的 schema 版本约定**（不另立一套），临时文件写入后原子替换；损坏时保留脱敏诊断并回到空历史。默认日志不记录完整路径、query 或窗口标题。
- 历史只在同一匹配等级内加权，不能让拼音超过字面、首字母超过全拼或中间匹配超过前缀。
- 文件、文件夹、应用和窗口标题支持全拼与首字母，不匹配父路径拼音。
- 至少两个拉丁字母才启用拼音；大小写、空格和撇号忽略，`v/ü` 等价；允许 `wx2026`、`weixinbeta`。
- `微信` 必须支持 `wx`、`weixin`、`weix`、`xin`，不支持 `eix`、`wxkaifa`；不做模糊读音或首字母/全拼混输。
- 支持简体、常用繁体和常见词组多音字，其他多音字采用版本化默认读音。
- 排名固定为字面 > 全拼 > 首字母；同层再比较精确、前缀、中间位置，然后历史，最后稳定 tie-break。
- 拼音命中返回对应汉字高亮区间。
- 文件/文件夹拼音数据使用独立版本化 sidecar，不扩大 12B `NodeSlot`；sidecar 缺失、损坏、版本不符或重建中退回字面搜索。
- sidecar 落在机器级目录时，必须同步更新 `dist/prism.iss` 的卸载清理清单（G3 已补 `%ProgramData%\Prism\`，本阶段新增文件不得遗漏），不允许只加生成逻辑。
- 拼音关闭后可选映射必须可释放；三进程合计拼音额外常驻内存不超过 10MB。

## Acceptance Criteria

- [x] 历史默认开启，可关闭、清除，500 条上限和 90 天淘汰均有确定性测试。
- [x] 失败/取消动作与网页查询不写历史，损坏历史文件不会阻塞搜索。
- [x] 字面/全拼/首字母/精确/前缀/中间/历史的优先级用跨类型固定语料锁定。
- [x] `wx`、`weixin`、`weix`、`xin`、`eix`、`wxkaifa` 及混合数字/拉丁后缀行为与规范一致。
- [x] 简体、常用繁体、多音词、默认读音、大小写、空格/撇号和 `v/ü` 有测试。
- [x] 高亮准确映射到汉字，不高亮父路径。
- [x] sidecar 关闭、缺失、损坏、版本不符和构建中均能完成字面搜索。
- [x] sidecar 已进入安装/卸载清单，卸载后不留残留文件。
- [x] 拼音关闭后可选映射释放；额外常驻内存 ≤10MB，三进程总内存 ≤100MB。
- [x] 暖查询 `max=8` P95 ≤100ms、`max=1000` P95 ≤300ms，ASCII 查询无不可解释回归。
- [x] Rust tests、Clippy、C# tests 和 WPF Release build 全部通过。

## Out Of Scope

- 父路径拼音、单字母拼音、模糊音、声调输入、自然语言分词；
- 云同步或跨设备历史；
- 网页查询历史；
- 把拼音字段塞入 `NodeSlot`。

## Dependencies

强依赖 G1、G3 与 G9。G3 必须先归档：本任务的历史文件是 G3 所定 schema 版本约定的第一个使用者，顺序反了会导致同一约定被发明两次并回改历史格式。G9 也应先归档：拼音 sidecar 的首建应复用 G9 的逐卷发布框架，而不是另建一套首建流程。G4、G5、G6 依赖本任务提供的历史与拼音契约。
