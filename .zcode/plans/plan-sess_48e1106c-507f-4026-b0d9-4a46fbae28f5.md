## 替换 Prism 应用图标

### 目标
用用户提供的 `E:\下载\Prism.svg`（1000×1000 矢量棱镜图标，深青色 `#0F3846`）替换现有 `prism.ico`。

### 步骤

1. **SVG → PNG → ICO 转换**
   - 用 Python 脚本将 SVG 渲染为多尺寸 PNG（256/128/64/48/32/16），再合成多尺寸 ICO
   - 优先用 `cairosvg`（如已安装）；否则 `pip install cairosvg pillow` 后重试
   - 生成标准多尺寸 ICO（256×256 降序），Windows/WPF/Inno Setup 兼容

2. **替换源文件**
   - `src/Prism/Assets/prism.ico` ← 新生成的 ICO（WPF `<Resource>`，TrayService 通过 `pack://` URI 加载）

3. **同步安装器副本**
   - `dist/prism.ico` ← 同一 ICO（Inno Setup 的 `SetupIconFile`、`UninstallDisplayIcon`、快捷方式图标都指向它）

4. **嵌入 EXE 图标（附带修复）**
   - 在 `Prism.csproj` 添加 `<ApplicationIcon>Assets\prism.ico</ApplicationIcon>`
   - 当前 EXE 不携带 Win32 图标，Explorer 中显示为通用图标；修复后 EXE 自身也显示棱镜图标

5. **验证**
   - `dotnet build src/Prism/Prism.csproj -c Release`（确认 Resource 和 ApplicationIcon 都正常）
   - `dotnet test src/Prism.Tests/Prism.Tests.csproj -c Release`（确认无回归）
   - 确认 `dist/prism.ico` 与 `src/Prism/Assets/prism.ico` 一致

### 不修改的文件
- `TrayService.cs` — 加载逻辑不变（`pack://application:,,,/Assets/prism.ico`）
- `dist/prism.iss` — 引用路径不变（都指向 `prism.ico`）
- `Prism.csproj` 的 `<Resource Include="Assets\prism.ico" />` — 保留（WPF 资源）

### 可选
- 将 SVG 源文件也保存到 `src/Prism/Assets/prism.svg` 作为设计源文件归档
