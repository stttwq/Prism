# Prism

Windows 11 桌面启动器与全盘文件名即时搜索工具，Listary 的替代品。常驻后台，按需呼出，一秒内给出全盘匹配结果，并集软件启动、网页快捷搜索、文件操作、窗口切换于一体。

## 它做什么

- **全盘文件名搜索**：直接读取 NTFS 主文件表（MFT）而非遍历目录，配合 USN 日志实时更新，输入即出结果，跨卷参与同一排序，不再按 MFT 顺序截断。
- **软件启动**：扫描开始菜单 `.lnk`，保留中文显示名，输入名称（如「微信」）回车即启。
- **网页快捷搜索**：预设引擎 `g`/`b`/`bi` 对应 Google/百度/Bing，可在设置新增任意网站关键词；裸域名直接打开浏览器。
- **拼音搜索**：首字母与全拼皆可，`wx`/`weixin`/`xin` 都能命中「微信」；内置约 130 条多音字词规则，sidecar 缺失时自动退回字面搜索。
- **查询过滤器**：`ext:pdf,doc` 按扩展名过滤，`path:"Project Docs"` 按路径过滤，二者与根范围相与，只返回文件/文件夹。
- **文件操作面板**：打开所在文件夹、复制/剪切、复制路径、重命名、复制到…、移动到…、移入回收站、永久删除、压缩为 ZIP、属性、打开方式、系统右键菜单；Shell 操作走 `IFileOperation`，保留系统原生冲突与进度界面。ZIP 优先 7-Zip，回退 Windows 11 内建。
- **动作快捷键**：每个动作可绑独立组合键（如 Ctrl+Shift+C 复制路径），保留键（方向/回车/Esc/Ctrl+G/Ctrl+数字）始终优先，导航不被打断。
- **暂存条与工作集**：搜索框下方文件条暂存待处理文件，LRU 淘汰；可把整组存为命名工作集，之后输入工作集名回车即载，整组可拖出到任意程序。
- **使用历史**：成功的打开/定位操作在同一匹配等级内加权，弱拼音不会盖过强字面；frecency 评分、14 天半衰期，可关闭与一键清除。
- **当前目录限定**：从资源管理器或 Directory Opus 呼出时可限定宿主当前目录（含子目录），`Ctrl+G` 在当前目录与全局间切换；识别失败立即退回全局，不复用旧目录。
- **窗口切换**：`>` 前缀进入窗口模式，匹配可见顶层窗口标题与应用名；过滤自身、工具窗口、其他虚拟桌面的窗口；HWND 不出 broker，激活前重新核验。
- **文件别名**：为一个文件/目录/程序绑一个或多个词，精确命中即触发。
- **在线建议**：默认关闭，开启后异步取 Bing/百度/Google 建议（800ms 超时，输入变更即取消旧请求），不进历史。
- **全局呼出**：默认连按两下 Ctrl，或自定义组合键；低级键盘钩子在独立消息泵线程，60 秒自愈重装；搜索框居中，Esc 或点外即隐。
- **深/浅色主题**：跟随 Windows 系统主题自动切换。

## 优势

- **内存极省**：三进程私有工作集之和以 ≤ 100 MiB 为硬门槛。MFT 记录池化（名以偏移+长度存入单条 `Vec<u8>`，每条约 40B 而非 100–130B），图标缓存按扩展名共享、窗口隐藏即释放，release 构建开 `opt-level=z` + LTO + 单码元 + `panic=abort` + strip。
- **即时索引**：MFT 直读 + USN 日志监听，首次构建后秒级延迟感知变更，与 Everything Search 同类技术。
- **逐卷增量首发**：系统卷先建完先可搜，其余卷后台续建并显示可解释进度，装后无整段不可用窗口。
- **权限分离而非注入**：索引以 LocalSystem 服务运行，Shell/剪贴板/设置/联网一律留在普通用户会话；接入资源管理器与 Directory Opus 用 Shell COM 与官方 `dopusrt`，无 DLL 注入。
- **版本化自愈持久化**：每个持久产物带 schema 版本与兼容默认值，原子临时文件替换，损坏则优雅降级（历史置空、拼音退字面、缓存触发重建），防半写。
- **封闭动作面**：固定 `ActionId` 枚举为协议上限，前端无法发明动作，broker 执行前重验目标存在性与类型。
- **跨卷全局 Top-K + 懒构造路径**：先算轻量候选，仅最终候选构造完整路径；根范围搜索的祖先遍历有界且带备忘上限。
- **隐私优先的联网**：建议与 favicon 默认关，favicon 需逐源授权，建议不进历史，HTTP 有重定向/MIME/大小/解码上限。
- **全程防陈旧**：序列号守护搜索结果（在途旧响应不覆盖新查询），索引变更走 generation 追踪，缓存键含 generation。
- **鲁棒快捷键**：低级钩子在独立泵线程，WPF 负载下不饿死；单例守护防重复注册并向已有实例发信号显窗。

## 平台与集成

- **系统**：仅 Windows 11 x64，需 .NET 8 Desktop Runtime。Windows 10、ARM64、x86 不在兼容承诺内。
- **文件管理器联动**：Windows 资源管理器（Shell COM `IShellWindows`，多标签感知）、Directory Opus 13.23（官方 `dopusrt`）；二者默认关闭，属实验性，需在设置开启。系统文件对话框暂不支持，回退全局。
- **语言**：界面、安装向导、动作标签全程简体中文；拼音搜索为内建核心能力而非可选。ASCII 文件名与应用名走同一套大小写不敏感字面匹配。
