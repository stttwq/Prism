# Prism

Windows 全盘文件名即时搜索与快速启动器。Listary 的轻量开源替代品。

三进程常驻后台，私有工作集总和 ≤ 100 MiB——比 Listary 单进程还轻。双击 `Ctrl` 呼出，
失焦即隐，深浅色跟随系统。开源免费，无会员、无广告、无遥测。

## Prism 解决什么

对标产品的痛点很明确：Listary 内存重、功能被会员墙切碎；Everything 界面简陋、不能自动隐藏、
呼出别扭。Prism 站在这两者之间的空地：**安静、薄、够用**。

## 核心能力

- **全盘即时搜索**：输入即出结果，1 秒内列出全盘匹配。基于 MFT/USN 直读索引，跨卷结果同一排序，
  不按盘符截断。首次安装逐卷发布，系统卷建完即可搜。
- **拼音搜索**：首字母与全拼并支持。`wx` / `weixin` / `weix` / `xin` 都能命中「微信」。
  含中文文件名搜索的中国用户开箱即用。
- **快速启动软件**：输入软件名回车启动，中文名（「微信」）直接命中。应用与文件统一排序，
  不无脑把应用顶到最前。
- **文件别名**：给高频文件绑自定义关键词（`weixin.exe` 绑 `wx`），打 `wx` 精确直达，
  独立于字面搜索的召回快车道。右键结果行即可设。
- **网页快捷搜索**：`g 关键词` Google、`b 关键词` 百度、`bi 关键词` Bing，默认浏览器打开。
  可在设置里加任意网站关键词。
- **查询过滤器**：搜索词后加 `ext:pdf` 按扩展名过滤、`path:"Project Docs"` 按路径过滤。
- **当前目录限定**：从资源管理器或 Directory Opus 呼出时可限定宿主当前目录，`Ctrl+G` 在
  当前目录与全局间切换。
- **完整动作面板**：选中结果按 `→` 弹出——打开所在文件夹 / 复制 / 剪切 / 复制路径 /
  重命名 / 复制到… / 移动到… / 回收站 / 永久删除 / 压缩 ZIP / 属性 / 打开方式 / 系统右键菜单。
  搜到即可处理，不用离开键盘。
- **动作快捷键**：常用动作可绑全局快捷键，搜索窗口内查表直触发。
- **使用历史**：打开过的文件在匹配等级内加权，越用越顺手。可一键清除。

## 优势

- **轻**：三进程合计 ≤ 100 MiB，比 Listary 单进程还轻。索引服务以 LocalSystem 运行只做只读搜索，
  Shell 操作与用户设置留在普通用户会话，权限边界干净。
- **安静**：双击 `Ctrl` 呼出，失焦即隐，深浅色跟随系统，动画顺滑。不抢焦点、不弹窗、不联网上报。
- **中文友好**：拼音搜索开箱即用，高频多音字词表人工核对（重庆/长沙/重启/弹窗等），
  目录链首字母匹配（`xz` 命中「下载/资料」下的文件）。
- **开源免费**：无会员、无功能墙、无遥测。代码托管在
  [github.com/stttwq/Prism](https://github.com/stttwq/Prism)。
- **可成长**：薄底座 + 内置 handler 路线，别名/动作快捷键等扩展不增进程负担。守住「薄」才有未来。

## 系统要求

**Windows 11 x64**，.NET 8 Desktop Runtime。Windows 10 / ARM64 / x86 不在兼容承诺内。

## 安装

下载 `dist\PrismSetup-1.1beta.exe` 运行。向导全程中文，可选安装目录（支持中文路径如
`D:\工具\Prism`）、开始菜单与桌面快捷方式、开机自启。安装需管理员权限（索引服务注册为
LocalSystem 服务）。开机自启走注册表 `HKCU\...\Run`，无需管理员常驻。

## 卸载

开始菜单 → 「卸载 Prism」，或「设置 → 应用」中卸载。卸载会停服务、退出常驻进程，
并清理便携模式的 `data` 目录与机器级 `%ProgramData%\Prism`（索引缓存和拼音 sidecar 都是
可重建的派生数据，删除不丢用户数据）。
